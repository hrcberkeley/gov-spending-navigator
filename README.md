# Gov Spending Navigator: FY2026 federal AI awards

An interactive map of all 5.19 million FY2026 USAspending award records, placed by what their descriptions say,
with one AI decision per award. Open `index.html` through a web server (for example GitHub Pages); the method is in
[METHODOLOGY.md](METHODOLOGY.md) and is also shown in the app.

Static build: award details are in gzip shards under `awards/`; tags stay in each visitor's browser.
